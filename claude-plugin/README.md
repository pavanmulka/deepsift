# DeepSift Search for Claude Code

Gives Claude Code live web search that returns **only the passages that answer the question**, not whole
pages. Four tools: `web_search`, `web_read`, `web_map` and `web_crawl`.

It runs on [Apify](https://apify.com/aadstra/deepsift-search) and is paid per use from your own Apify
account: $4 per 1,000 searches, $1 per 1,000 pages read. A free Apify account includes $5 of credit every month.

## Set up

1. Get your Apify API token at https://console.apify.com/settings/integrations
2. Install the plugin; Claude Code asks for the token once and keeps it in your system's secure store.

Prefer to run it on your own computer for free with your Claude subscription? See the
[self-hosted DeepSift](https://github.com/pavanmulka/deepsift).
